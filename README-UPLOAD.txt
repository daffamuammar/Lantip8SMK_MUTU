LANTIP 8 — STATIC SOURCE (HTML/CSS/JS)

Upload seluruh isi folder ini ke public_html atau root GitHub Pages.
Pastikan index.html, styles.css, dan script.js berada langsung di folder utama.
Tidak membutuhkan Node.js, npm, npm run dev, React, atau build step.
Seluruh konten website ditulis terbaca di index.html; styling berada di styles.css; interaksi berada di script.js.
